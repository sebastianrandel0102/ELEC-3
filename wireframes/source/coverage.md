## Notes on individual surfaces

- **006 Change Password:** Google verification is shown for a linked Google account.
- **011 Today:** Full scroll composition. The Assist section is hidden by default and can be enabled.
- **037 Save Together:** Owner view. Non-owner members see Leave goal instead of owner management controls.
- **063 Savings Pulse:** Expanded wireframe of the embedded Savings Pulse component, not a separate route.
- **073 SaveTrack AI:** Illustrative conversation text.
- **084 Speak naturally:** Voice panel within Agent Studio.
- **085 Review your transcript:** Transcript-review state within Agent Studio.
- **098 What-If scenario:** Action preview embedded in an Agent mission.
- **099 Equal goal allocation:** Action preview embedded in an Agent mission.
- **103 Voice & audio:** Expanded view of controls within Agent settings, not a separate route.
- **115 Savings Goal · Compact:** Illustrative full-details layout; launcher dimensions determine the exact content.
- **116 Today's Planner · Compact:** Full Details with task titles enabled.
- **117 Quick Save · Compact:** Representative supported size. Narrow widgets page through number keys.
- **118 Today Overview · Compact:** Overview uses the selected goal and today's task summary.
- **119 Savings Goal · Medium:** Illustrative full-details layout; launcher dimensions determine the exact content.
- **120 Today's Planner · Medium:** Full Details with task titles enabled.
- **121 Quick Save · Medium:** Representative supported size. Narrow widgets page through number keys.
- **122 Today Overview · Medium:** Overview uses the selected goal and today's task summary.
- **123 Savings Goal · Expanded:** Illustrative full-details layout; launcher dimensions determine the exact content.
- **124 Today's Planner · Expanded:** Full Details with task titles enabled.
- **125 Quick Save · Expanded:** Representative supported size. Narrow widgets page through number keys.
- **126 Today Overview · Expanded:** Overview uses the selected goal and today's task summary.
